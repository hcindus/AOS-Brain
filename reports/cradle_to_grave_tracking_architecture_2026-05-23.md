# Cradle-to-Grave Identity Tracking Architecture
## Summary Document — 2026-05-23

---

## Overview

Humans become trackable "units" through a fragmented network of institutions — each cataloging a different dimension. There is no single central database. Instead, an ecosystem of government agencies, private corporations, and data brokers maintains overlapping identity records from birth to death.

---

## The Tracking Pipeline

| Stage | Document | Primary Catalogers | Data Tracked |
|-------|----------|-------------------|--------------|
| **1. Birth** | Birth Certificate | State Vital Records, NCHS | Name, DOB, parents, sex, location |
| **2. Identity Key** | Social Security Number | SSA | Lifetime ID, earnings, mortality |
| **3. Economic** | Tax Records | IRS | Income, employment, business, estate |
| **4. Financial Behavior** | Credit Files | Equifax, Experian, TransUnion | Credit, debt, repayment, risk scores |
| **5. Education** | School Records | K–12 districts, Universities | Performance, demographics, outcomes |
| **6. Health** | Medical Records | Hospitals, Insurers, Actuaries | Diagnoses, biometrics, mortality risk |
| **7. Employment** | Payroll/HR Records | Employers, ADP, Workday | Wages, productivity, tenure |
| **8. Digital Behavior** | Platform Profiles | Google, Meta, Apple, Amazon, Data Brokers | Searches, purchases, location, social networks |
| **9. Demographics** | Census Records | US Census Bureau | Population, migration, workforce |
| **10. Death** | Death Certificate | State Vital Records, SSA, IRS | Cause, time, location, next of kin |
| **11. Archival** | All Prior Records | National/State Archives | Permanent historical retention |

---

## Condensed Pipeline

**Birth Certificate → SSN → IRS → Credit Bureaus → Education → Health → Employment → Digital Platforms → Census → Death Certificate → Archives**

## Key Institutions by Dimension

| Dimension | Who Tracks |
|-----------|------------|
| Identity | Vital Records, SSA |
| Economic Activity | IRS, Credit Bureaus |
| Labor Value | Employers, Payroll Systems |
| Health & Mortality | Insurers, Actuarial Firms |
| Behavior | Tech Platforms, Data Brokers |
| Demographics | Census Bureau |
| Legal Status | Courts, DMV, SSA |

---

## Data Brokers (Shadow Catalogers)

- Acxiom
- LexisNexis
- Oracle Data Cloud

These entities build identity graphs from purchases, location data, online behavior, and demographic traits — often without user knowledge.

---

## Key Insight

There is **no single institution** cataloging human resources. The system is a **network of fragmented, powerful, and largely uncoordinated institutions** — each with economic incentives to track human activity.

This architecture is not secret. It is not unified. It is not benevolent. It is simply the emergent result of economic, actuarial, and administrative necessities.
