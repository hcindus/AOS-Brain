# 5-Point Scene Builder

The one prompt template behind every scene in every production. Same five points, same discipline — only the output form changes by medium.

## The Five Points

1. **Voice/Character** — who (or what) is on screen: identity, look, sound, and what they want.
2. **Setting** — where it happens: the world, environment, ambient.
3. **Structure** — the arc, beat by beat.
4. **Direction** — the shot/cue vocabulary + placement rules.
5. **Tone & pacing** — the emotional arc + how to hold the beats.

## Output forms (diversity within guardrails)

| Medium | Output form |
|--------|-------------|
| **Music video** | Scene treatment — VISUAL / LYRICS / ACTION + director's notes + color/mood/symbolism |
| **Film / series scene** | Shot-level scene prompt — action + dialogue + shot variation + reference images |
| **Comedy / monologue** | Script — dialogue + parenthetical cues |
| **Dance / no-dialogue** | Movement treatment — beats + atmosphere, no dialogue |

## Consistency lock (the Production Bible)

Every production has a bible of things that never change, across every scene:

- **Character** — same face/voice/clothing across every render (SoulID reference images locked once).
- **World** — same venue/location/palette across scenes.
- **Format** — same cue discipline, same treatment structure.

Lock the bible first, then generate scenes. Consistency is what makes a production read as one piece, not a pile of renders.

## Music video (MV) — first-class form

One song = one treatment. The arc follows the track beat-for-beat: intro → verse → chorus → bridge → peak → outro.

- **VISUAL** — what's on screen each beat (camera, subject, palette).
- **LYRICS** — the line synced to that beat.
- **ACTION** — the movement / performance.
- **Director's notes** — color, mood, symbolism, story arc. A scene-by-scene treatment, NOT a shot-list.

## Rules

- Five points, every scene, no exceptions — consistency compounds.
- Read every scene prompt before rendering; edit the prompt, never re-render blind.
- Lock the bible first (cast once, shoot every scene).
- Direction cues land only after the beat/punchline, never mid-setup.
