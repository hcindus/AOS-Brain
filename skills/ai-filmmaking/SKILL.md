# AI Filmmaking — Master Playbook

**One thread runs through every step: quality comes from the process, not luck.** Clear script → structured prompts → trained character → intentional edits.

**Toolchain:** Claude (scripting) + 7ART (production) + CapCut (editing) + the studio (series scaling).

## The full pipeline

| Stage | What you do | Skill |
|-------|-------------|-------|
| 1. Script | Write a clear script / logline with Claude | *(core — see below)* |
| 2. Character | Train a consistent character (SoulID) as your recurring face | `youtube-content-creation` |
| 3. Produce | Generate visuals in 7ART with structured prompts | *(core)* |
| 4. Edit | Cut in CapCut, add sound (Voice/Music/Foley/Lipsync) | *(core)* |
| 5. QA & export | 3-watch self-review, export 16:9 + 9:16 | `trailer-export-self-review` |
| 6. Publish | YouTube (film + Short), TikTok, Reels | `youtube-publish-film` · `short-form-social-posting` · `cross-platform-publish-order` |
| 7. Monetize | Freelance / audience / products | `freelance-ai-video-production` · `youtube-content-creation` · `sell-digital-products` |
| 8. Scale | First $500, then film → series | `first-500-launch-plan` · `scale-film-to-series` |

## Division of labor (the marriage)
- **Mortimer** (logic/pattern/technical) owns **production**: the studio, SoulID character consistency, rendering, scene/series generation — the analytical "cast once, shoot every episode" discipline.
- **Miles** (sales/strategy) owns **go-to-market**: pricing, retainers, publishing, distribution, and monetization paths.

They meet at the export: Mortimer produces a finished, consistent film; Miles turns it into income and reach.

## Sub-skills (index)
- `trailer-export-self-review` — export + 3-watch QA (scroll/beat/want-more)
- `youtube-publish-film` — full film + vertical Short, search-optimized
- `short-form-social-posting` — TikTok + Reels captions/hashtags/first-hour engagement
- `cross-platform-publish-order` — YouTube first, link-everywhere move
- `freelance-ai-video-production` — Path A: pricing by deliverable, retainers
- `youtube-content-creation` — Path B: AI character host, batch workflow, monetization ladder
- `sell-digital-products` — Path C: prompt packs, presets, guides, templates
- `first-500-launch-plan` — 14-day plan + pricing ladder (50%→200% market)
- `scale-film-to-series` — pilot → season (writing stages, cliffhanger chain, costs/ceilings)

## Rules
- Process over luck — never skip the script or the outline; frames are where the credits go.
- One consistent character across everything — familiarity compounds.
- Export before you review; publish YouTube first; link everywhere.
- Price by result, not hours; over-deliver to open the retainer; free is a trap.
