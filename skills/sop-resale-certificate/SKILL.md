# SOP-005 — Resale Certificate Management

**KPI:** 100% of resellers have a valid, on-file certificate · renewals flagged 30 days before expiry.

## Process
1. **Collect** — request the customer's resale/tax-exemption certificate at onboarding.
2. **Verify** — confirm validity (state, ID number, expiration) against the issuing state.
3. **Store** — file in the customer record (lead portal / CRM), linked to the account.
4. **Renew** — flag expiry 30 days out; send renewal reminder before it lapses.

## Rules
- Never ship tax-exempt without a valid, current certificate on file.
- Mark accounts `TAX-EXEMPT` only after verification.
- Log every certificate (issue date, expiry, state, number).
