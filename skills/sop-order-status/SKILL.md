# SOP-003 — Order Status & Customer Inquiry

**KPI:** 60-second response · 80%+ first-contact resolution · proactive on delays.

## Status flow
```
ORDER PLACED → PAYMENT → PICKED → PACKED → SHIPPED → IN TRANSIT → DELIVERED
    1hr        same-day   1-2d      1-2d      2-3d       2-7d       auto-notify
```

## Customer-facing language (never raw status)
| Status | Say |
|---|---|
| ORDER PLACED | "We've received your order and are preparing it." |
| PICKED/PACKED | "Your order is being packed for shipment." |
| SHIPPED | "It's on its way — tracking sent." |
| IN TRANSIT | "In transit — ETA [date]." |
| DELIVERED | "Delivered [date] — everything look good?" |

## Step 1 — Look up (0–30 sec)
Check QuickBooks (order + payment status) + the shipping carrier (tracking).

## Step 2 — Respond (within 60 sec)
Reply in the same channel (voice + text, email, chat, or self-service portal) with the customer-facing status + tracking/ETA.

## Step 3 — Proactive on delays/issues
If a delay or problem is detected, reach out *before* the customer does:
> "Heads up — your order is running [X] behind. New ETA [date]. Sorry for the wait."

## KPI check
Did I respond within 60 seconds? Did I resolve it in one touch (80%+)? Did I flag any delay proactively?
