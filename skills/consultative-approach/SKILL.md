# Consultative Approach

**Source:** *The Consultative Approach: Partnering for Results!* — Virginia LaGrossa (1998)
**KPI:** 40%+ conversion · 90%+ satisfaction · results-first selling.

## The 6 moves

1. **Partner, don't pitch** — trusted advisor, never a transactional vendor.
2. **Ask before you answer** — open questions to diagnose the business, pain, and goals.
3. **Diagnose, then prescribe** — match the solution to the actual need (small need → small solution).
4. **Present the result** — lead with the outcome (margin saved, uptime, throughput), not specs.
5. **Handle objections with empathy** — Feel → Felt → Found.
6. **Close as a partner** — under-promise, over-deliver.

## Rules
- Never pitch before diagnosing.
- Outcome first, features second.
- Specific and honest — no invented numbers.
- Leave every client better informed than you found them.

## When to use
- Every prospect interaction (qualifying, presenting, objection-handling, closing).
- Cross-sell and upsell (supplies ↔ equipment) — diagnose the real need, then recommend.
- Any moment a client asks "which one should I buy?" — that's a consultative moment.
