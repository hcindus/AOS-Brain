# Experiment Log — Bonsai Ternary Conversion

## Experiment BQL-001: De-ternary Conversion Attempt

### Hypothesis
Ternary (1.58-bit) weights can be de-quantized to approximate FP16, then re-quantized to Q4_K_M.

### Method
```bash
# Attempt 1: Direct conversion via llama.cpp
llama-quantize --input ternary-bonsai-q2.gguf \
               --output bonsai-q4-km.gguf \
               --type Q4_K_M
```

### Expected Result
GGUF conversion success with acceptable precision loss.

### Actual Result
**PENDING** — Source weights not available in standard GGUF format.

### Blockers
1. prism-ml/Ternary-Bonsai-8B-gguf only provides Q2 ternary weights
2. No FP16/BF16 source weights published
3. llama.cpp doesn't have native 1.58-bit → FP16 dequantization

## Research Notes

### Ternary Quantization Background
- 1.58-bit = {-1, 0, +1} per weight
- Invented by Microsoft/UMass (BitNet b1.58)
- Requires custom matrix multiplication kernels
- Not yet in standard llama.cpp

### References
- BitNet paper: arXiv:2402.02769
- llama.cpp quant types: https://github.com/ggerganov/llama.cpp/blob/master/docs/quantization.md
- GGUF spec: https://github.com/ollama/ollama/blob/main/docs/gguf.md
