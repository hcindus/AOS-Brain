### Core Zapier Concepts

- **Zap**: An automated workflow (trigger + action)
- **Trigger**: Event that starts the workflow (e.g., "New Shopify Order")
- **Action**: What happens next (e.g., "Send Slack Message")
- **Task**: Each time a Zap runs = 1 task
- **App**: Connected service (Shopify, TikTok, Gmail, etc.)
