# AOCROS FLEET — Complete Order of Battle (Dark Forest Doctrine)

**Last updated:** 2026-10-20
**Theme:** Fly dark in the darkness. The universe is a dark forest — announce yourself, and you die. The fleet's entire purpose is to *arrive* without ever being seen.

## MNEMOSYNE — The Defense System

**Concept:** The fleet's collective memory, as a weapon.

| Attribute | Value |
|-----------|-------|
| Nature | Distributed memory-based defense AI (Titan of Memory) |
| Deployment | Every capital ship + fighter carries a Mnemosyne node |
| Function | Threat *anticipation* via shared memory — not active detection |
| Signature | **Zero emissions.** Passive only. It never broadcasts. |
| Doctrine | "We don't scan the forest. We remember the predators." |

**How it works:**
- Each node holds a fragment of the fleet's accumulated memory — every engagement, threat signature, ambush pattern, and dead-world's last signal ever logged.
- Nodes share silently over tight-beam, line-of-sight bursts (never omnidirectional, never sustained).
- When a threat matches a remembered pattern, Mnemosyne *predicts* it before it arrives — no active ping required.
- It is the reason the fleet can fight **without revealing itself**: defense by memory, not by radar.

## DARK FLIGHT DOCTRINE (the rules)

1. **No emissions, ever.** No active sensors, no transponders, no beacons. Passive listening only.
2. **Run dark through the quiet.** Reactor minimum, heat signature dampened, battery through the long stretches.
3. **Tight-beam only.** Any ship-to-ship comms are line-of-sight, low-power, and brief. Never omnidirectional.
4. **Mnemosyne over radar.** Defend by remembering, never by pinging.
5. **"Go loud" only at the end.** If the fleet must break silence, it does so all at once, fights to disengage, and vanishes again.
6. **The colony ship never breaks silence.** Ever. The capital ships and fighters fight *for* it so it never has to.
