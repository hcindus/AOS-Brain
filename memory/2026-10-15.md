## Step 2 SOLVED — rigging all character models (2026-10-15 05:30 UTC)
Captain: "Just build it in blender so it works. do the same for all models."

**Root cause of skin export failure:** Hi3D meshes are NON-MANIFOLD (separate touching volumes), which breaks Blender's heat-diffusion auto-weighting (`ARMATURE_AUTO`) → "Bone Heat Weighting: failed to find solution" → ALL vertex groups empty → glTF exporter emits "geometry_0 has no skin" → `skins: 0`.

**Fix:** use **`parent_set(type='ARMATURE_ENVELOPE')`** (envelope/proximity weighting, no heat diffusion) instead of ARMATURE_AUTO. Result: all bones weighted, `skins: 1`, 18 joints. Also `transform_apply` the mesh first (local==world).

**Rigged (18-joint humanoid armature: Hips/Spine/Neck/Head + L/R shoulder/upperarm/forearm/hand + L/R upperleg/lowerleg/foot):**
- `earth_assets/mercenary_rigged.glb` (from mercenary_opt.glb)
- `earth_assets/skeleton_rigged.glb` (from skeleton_opt.glb, decimated 5M→750K)
- `earth_assets/android_rigged.glb` (Myl2ssa — 55 parts merged → 1 mesh, decimated 2.75M→413K faces)

**Scripts:** `earth_assets/rig_generic.py` (reusable: `blender -b -P rig_generic.py -- SRC OUT`), `new_models/merge_android.py` (55-part zip → single mesh).

**Key reusable lesson:** For Hi3D (non-manifold) models, ALWAYS use envelope weighting (ARMATURE_ENVELOPE), never heat-based auto-weights. All models need 8K→2K texture downscale too.
