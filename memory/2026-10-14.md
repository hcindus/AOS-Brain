- **Lesson:** Blender 4.2 Draco output ≠ three.js 0.160 decoder compatibility. Prefer plain GLB for web; decimate to control size. Verified via a `/tmp/draco_test` Node harness (three@0.160 + GLTFLoader + fetch/ProgressEvent shims).
