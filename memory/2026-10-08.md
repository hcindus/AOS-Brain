
## Embodied-AI hardware thesis — LeCun + edge memory + us (one through-line)

- **Micron/MU** = memory (DRAM/HBM) for the AI buildout. HBM is the real compute-stack bottleneck (supply-constrained → peak margins > Nvidia). BUT DRAM is deeply cyclical (boom-bust 40yrs) — "higher margins than Nvidia" is a *peak-cycle* number, not a structural moat (unlike Nvidia's CUDA).
- **The sharpest comment:** "edge AI devices — cars, robots, computers — will use 400% more AI memory." This is the *hardware expression of LeCun's world-models thesis*: embodied AI runs **on-device** (a robot/car can't wait for cloud latency — 47s→1s planning), and on-device world models are memory-hungry in a way cloud LLMs aren't.
- **The one thesis, three layers:** LeCun = *why* (world models > chatbots); Micron/HBM = *how* at hardware layer (memory for on-device models); AGI Company = *what* (the embodied intelligence itself).
- **Risk (the smart comment):** "This depends on hyperscaling. If the bubble pops, so does this. Massively." Edge-AI memory = durable (robots/cars still need memory if cloud deflates); HBM-to-hyperscalers = fragile (capex-cycle).

This is the same through-line as the Steve Jobs (software>hardware moat) + LeCun (world models) notes — all one coherent "embodied AI is the next wave" argument, from intelligence → memory → application layers.
