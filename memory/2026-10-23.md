# 2026-10-23 — RP1 Training Room (Captain directive)

Captain shared the RoboParty **RP1** open-source humanoid and asked me to (1) pull the code, (2) review it and "make it our own," (3) build a **training room** so our agents can train in sim before "entering the real world."

## What I did
- Cloned the **full RP1 ecosystem — 16 repos** under `robotics/rp1/`:
  - Hardware: `rp1_hardware`, `ROMOMO`, `rp_dexhand`
  - Models: `RP1_description` (URDF + MJCF)
  - Software: `RP1_firmware`, `roboparty_deploy`, `Party_OS`, `roboparty_joystick`, `rp1_test`
  - Learning: `UFO` (unsupervised RL, MuJoCo/mjlab), `roboparty_train` (Isaac Lab), `MimicLite`, `P-BFM`, `I-BFM-Code`, `INTACT-JEPA`, `robolab` (AMP/BeyondMimic/Parkour)

## Key hardware reality (said out loud before building)
This VPS has **no GPU** (4-core AMD EPYC, 15GB RAM, no CUDA). Full RL training needs silicon: UFO → CUDA 12.8 + 8×H20 reference; Isaac Lab → NVIDIA GPU. So Captain chose **option B: CPU-first, GPU as plug-in socket**.

## Training Room built (`robotics/training_room/`)
- `gym/` — `RP1GymEnv`: MuJoCo sandbox. Loads `rp1_flat.xml` (robot + floor), 28 torque actuators, 500 Hz. reset/step/observe/reward ("stand and walk" task).
- `pilots/` — Pilot ABC + baselines (`zero`, `random`, `hold` PD-stand) + `OllamaPilot` (wraps any Ollama model as a torque controller).
- `agents/roster.json` — our models mapped as pilots: mort_ii, qwen35, qwen25, deepseek, hermes2, tinyllama + 3 baselines.
- `graduation/` — blind hold-out (stand/walk/push-recovery) + gate that routes through the **RiP GoR council** via `/tmp/aos_brain.sock` (falls back to threshold if socket down). Logs to `runs/graduation_log.jsonl`.
- `dispatch/` — `TrainingBackend` ABC; `LocalCPUBackend` (now) + `GPUBackend` (socket for cloud/dedicated box).
- `train.py` — CLI: `roster` / `eval <pilot>` / `graduate <pilot>`.

## Verified working
- MuJoCo 3.17 installed in `training_room/.venv`.
- `zero` → 9% alive; `hold` → 29% alive (pipeline discriminates correctly).
- `graduate hold` → 0.31 `BACK_TO_TRAINING`; `graduate zero` → 0.066 `BACK_TO_TRAINING`.
- `OllamaPilot` (tinyllama) produced a valid 28-torque action, parsed + clipped. Ollama bridge confirmed.

## Notes / gotchas
- `robot.xml` has **no floor** — must use `rp1_flat.xml` / `rp1_rough.xml` (the scene files include robot.xml + ground).
- Ollama cold-start is slow (tiny model >10s first call) — bumped default timeout to 60s. Full episodes with an LLM pilot would be impractically slow; the real training path is the GPU dispatch socket (UFO / Isaac Lab).
- Committed training_room source only; `robotics/rp1/` + `.venv/` + `runs/` gitignored (rp1 clones are third-party, own git, 2.4G).
