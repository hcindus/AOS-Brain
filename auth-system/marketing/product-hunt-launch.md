We built Sentinel Shield because we were tired of paying $20K+/year to Auth0 for basic auth, while still getting breached.

🛡️ **Sentinel-Dusty Guardian** - Real-time threat detection that monitors for brute force, credential stuffing, and suspicious activity

- Complete audit logging
- React admin dashboard
- Docker deploy in 5 minutes
