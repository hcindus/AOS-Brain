## MIDDLE — the Seam 🔶 (the core of the improvements)

- 🆕 **Motion Verb Layer** — explicit primitives: `present` · `orient` · `reach` · `shift` · `step` · `settle` (+ `stand`/`sit`/`hold`/`release`/`walk`/`stop`). Each carries affect-modulation (Cortex) + safety-envelope + priority vs. expression. Returns **accepted / rejected / aborted + reason**.
- 🔴 **Safety Contract** — living invariants; "machine can say no" is **expressible, not a silent veto**. Every verb + actuator group declares its safety invariants before integration.
- 🆕 **Dual-Heart Arbitration** — physical pump loop (safety-critical, hard real-time) vs. affect cadence loop (software, proposes rate/stroke). Affect accepted only inside a safe band from Thyroid + thermal + actuator demand. Heart-rate/rhythm = first-class expression channels.

---

## BOTTOM — the Body (hardware)

- **Control stack** — existing 5-tier (RT kernel → motor firmware → neural bus → behavior → cognitive) + independent safety layer.
- **Skeleton + actuators** — hybrid: electric (QDD/SEA) for load-bearing hips/knees/shoulders; muscle (TCPA/McKibben) for spine/neck/face/hand.
- **Presence engine** — affect → 30-motor expression.
- 🆕 **Unified Thermal-Vascular Service** — Thyroid as sole thermostat; two circuits (core high-flow + peripheral capillary bed); modular replaceable capillary panels.
- 🆕 **Phased Structural Battery** — 3 stages (conventional pack → hybrid → load-bearing), with exit criteria; skeleton energy reported to Thyroid as state.

---

## FOOTER — risk-reduced build order

Surfaces integration problems early: static structural + scapula + COBRA spine → single arm/hand (full DOF) → presence + dual-heart + thermal on fixed torso → full bipedal (only after presence + balance solid) → full skin + vascular last.
