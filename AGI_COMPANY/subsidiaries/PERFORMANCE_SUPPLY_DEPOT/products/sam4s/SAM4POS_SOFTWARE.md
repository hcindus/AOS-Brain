# SAM4POS — Software Platform (runs on SAM4S hardware)

**Source:** SAM4S product brochure + docs (pulled 2026-08-21)

## What it is

SAM4POS is the integrated POS **software** that runs on the SAM4S ECR + POS terminal hardware. Your authorized dealer configures a custom application from a feature array for food/retail operators. This is the "complete system" story — hardware + software + peripherals.

**Hardware that runs SAM4POS (per Captain):** **SAPPHIRE** (Windows POS terminal) + **SAP-630** (restaurant ECR).

## SAM4POS Android — value proposition (from official video)

**The core problem it solves:** "each type of business uses different software" → fragmentation + on-site support burden. SAM4POS Android = **one software for many business types.**

**Dealer-side benefits (this is the margin story):**
- **Remote support via TeamViewer** — solve client issues without visiting the store (kills the biggest dealer cost)
- **Device management server** — license management, version updates, real-time device state, customer management from one pane
- **Network sync** — stations synchronized, flexible promotions

**Customer-side benefits:**
- Table management (few touches), faster ordering
- Custom receipts/labels per store, peripheral connectivity
- Automatic end-of-day, monthly snapshot, database-style reporting (view/print any report), reports by email
- Runs on **POS terminal AND tablets**; reports viewable on **mobile phones**

**Tagline:** "Sam4POS will guide you to success."

→ This is the exact copy angle for SAP-630 / SAPPHIRE Android / ZETA-A50 pages: lead with "one software for every business type" + "we support you remotely, no site visit."
