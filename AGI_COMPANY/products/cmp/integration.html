How It Works

1. Script Blocking: Scripts with data-agi-category are blocked until consent is given.

<script type="text/plain" data-agi-category="analytics">
  // Analytics code here - won't execute until consent
</script>

2. Google Consent Mode: Automatically integrates with GTM Consent Mode v2.

3. Automatic Execution: Once consent is granted, blocked scripts are automatically allowed.
