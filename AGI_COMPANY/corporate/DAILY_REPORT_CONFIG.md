## Email Setup (Required)

Since no mail system is currently installed, reports are saved to:
`/root/.openclaw/workspace/reports/`

### To Enable Email Delivery:

**Option 1: Install Postfix**
```bash
sudo apt-get update
sudo apt-get install postfix mailutils
# Configure as "Internet Site" during setup
```

**Option 2: Use External SMTP (Gmail/SES/etc)**
Edit `/root/.openclaw/workspace/scripts/daily_report.sh` and update the Python email section with SMTP credentials.

**Option 3: Manual Retrieval**
Reports are saved daily to:
```
/root/.openclaw/workspace/reports/daily_2026-04-19.txt
/root/.openclaw/workspace/reports/daily_2026-04-20.txt
# etc.
```
